# Product concept

Daily Compass turns a daily fortune into a short reflection ritual:

1. **Signal:** a non-certain theme selected by versioned rules.
2. **Why:** the source context and rule category behind it.
3. **Action:** one optional, reversible and low-risk suggestion.
4. **Reflection:** an evening relevance/usefulness check and optional note.

Tone: calm, curious and non-fatalistic. Example: “Communication may be worth extra care today. Before sending an important message, reread it once.” The system never asserts that the theme must occur.

Initial target is adults interested in a short daily ritual. The assumption that this loop creates repeat value needs interviews and pilot data.
