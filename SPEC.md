# Specification

Status: design proposal. Official requirements: features (4.1), market position (4.2), technical blueprint (4.3), storage decision and ERD (4.4), success/performance KPIs (4.5). See `ANSWER.md` for the submission-ready response.

**User:** an adult seeking a brief daily reflection. **Platform:** responsive web POC. **Method:** astrology-inspired interpretation. **Core loop:** Signal → Why → Action → Reflection.

Functional POC scope: general daily reading; optional local Sun-sign context; Tarot question with one- or three-card spreads; source/rule/card explanation; low-risk action; optional evening rating and note. No account is implemented. The wider design covers day/week/month/year horizons, love/career/study/money topics, I Ching decisions and later Vedic timing. Nonfunctional scope: one stable daily reading per browser/local day, transparent randomness for Tarot, grounded text, safe fallback, private reflection and version traceability. No production claims or numeric performance targets are assumed.
