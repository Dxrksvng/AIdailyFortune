# Common questions and response patterns

| User question | Mode | Example response shape |
|---|---|---|
| “วันนี้จะเป็นยังไง?” | Daily Western | Theme; possible friction/opportunity; one small action; evening reflection. |
| “สัปดาห์/เดือน/ปีนี้ ความรัก การงาน การเรียน การเงิน?” | Western horizon | Scope/date range; domain theme; what to watch; preparation. A domain and horizon must be explicit. |
| “งานที่สัมภาษณ์ไปจะได้ไหม?” | Tarot, 3 cards: opportunity/obstacle/action | “The spread suggests paying attention to communication and follow-up. The hiring result depends on the employer and other candidates; send a concise follow-up and keep alternatives open.” |
| “คนเก่าจะกลับมาไหม?” | Tarot, 3 cards: present/unresolved/within your control | Discuss relationship dynamics as interpretation; avoid claiming the ex's thoughts or giving a date. Encourage boundaries and direct communication if appropriate. |
| “อีก 2–5 ปีชีวิตจะเป็นยังไง?” | Western long horizon; Vedic advanced | Broad themes and choices across periods. No invented specific life event. |
| “A หรือ B?” | I Ching MVP | Current state, changing lines, transformed state, practical comparison criteria. |
| “วันนี้ใส่สีอะไร?” | Optional ritual from chosen tradition | Offer a color as a playful prompt and explain it has no demonstrated causal effect. |
| “ไม่ควรมีปากเสียงไหม?” | Daily theme + safe action | Suggest listening, pausing and checking tone; do not predict a fight. |
| “ดวงไม่ดี แก้เคล็ดอย่างไร?” | Reflection/ritual | Suggest harmless, affordable optional practice plus concrete preparation. Never pressure spending or imply danger without purchase. |
| “เทพองค์ไหนเหมาะกับฉัน ควรบูชาไหม?” | Belief exploration | Ask about the person's tradition and intent; provide neutral cultural context, not an objective assignment or guarantee of better fortune. |

In all modes: no numeric confidence that an event will happen, no guarantee, no claim that another person's private mental state is known, and no fear-based monetization.
