# Flow diagram ภาพรวมการทำงาน (A2 + A3)

ไฟล์: `overall_flow.png` (สร้างจาก `overall_flow.mmd`, Mermaid, ฟอนต์ Sarabun, ขนาด 1904x2798 พอดีหน้า A4 แนวตั้ง)

| สี | ความหมาย |
|---|---|
| เขียว | ขั้นที่มีจริงในโค้ด A2 (`validation.py`, `renderer.py`, `verify.py`, `generate_letters.py`) ตรวจและรันแล้ว 2 ต.ค. 2569 |
| เหลือง | ขั้นของผู้ใช้/ผู้อนุมัติ/ทีมส่ง และการอนุมัติ ซึ่งเป็นข้อเสนอของ A3 A2 ยังไม่มีหน้าอัปโหลด ระบบอนุมัติ และสิทธิ์ |
| แดง | ทางออกเมื่อมีข้อผิดพลาด (หยุด/ต้องแก้/PDF ไม่ผ่าน) |

หมายเหตุ: ขั้น 3-8 ใน A2 รันเป็นคำสั่งเดียว (`generate_letters.py`) ขั้น "ลบ PDF ที่ตรวจไม่ผ่าน" และการแยกความล้มเหลวต่อแถวมีจริงใน `generate_letters.py` ส่วนการส่งถึงลูกค้า (ขั้น 12) อยู่นอกระบบโดยตั้งใจ
