# คู่มือการใช้งาน: สร้างเอกสาร PDF จากไฟล์ Excel

> **สำหรับ:** พนักงานที่เตรียมไฟล์และสร้างชุดเอกสารถึงลูกค้า (ไม่ต้องมีพื้นฐานด้านเทคนิค ถ้าเคยใช้ Excel / Google Sheets และอีเมลได้ ก็ใช้ได้)
> **เวอร์ชันคู่มือ:** ร่าง 0.1 · 2 ตุลาคม 2569
>
> **หมายเหตุสำคัญก่อนใช้คู่มือนี้:** ชื่อปุ่ม เมนู และหน้าจอในคู่มือเป็น **ต้นแบบการออกแบบ** ของแพลตฟอร์มที่ยังไม่ได้สร้าง เมื่อสร้างระบบจริงต้องแก้ชื่อและเพิ่มภาพหน้าจอจริง และให้ผู้ใช้จริง 3–5 คนลองทำตามคู่มือก่อนแจกจริง ชื่อทีม ชื่อผู้รับผิดชอบ และเบอร์ติดต่อด้านล่างเป็นช่องว่างให้เติม

## หน้านี้หน้าเดียวพอ (สรุปสั้น)

ระบบนี้ทำงานคล้าย **Mail Merge** ใน Word แต่มี "ด่านตรวจ" เพิ่ม:

```
เตรียมไฟล์ Excel  →  อัปโหลด  →  ดูผลตรวจ  →  แก้ไฟล์ (ถ้ามี)
      →  ดูตัวอย่าง  →  ขออนุมัติ  →  ดาวน์โหลด PDF  →  ส่งตามช่องทางที่บริษัทกำหนด
```

**3 ข้อที่ต้องจำ**

1. **ใช้ไฟล์แม่แบบจากระบบเสมอ** และไม่เปลี่ยนชื่อหัวคอลัมน์
2. **ถ้าระบบบอกว่ามีแถวต้องแก้ ให้แก้ที่ไฟล์ Excel แล้วอัปโหลดใหม่** ไม่ต้องแก้ PDF เอง
3. **ถ้ามีอะไรดูผิดปกติ อย่าส่ง** หยุดแล้วแจ้งหัวหน้าทีมพร้อม "เลขชุดงาน" และ "เลขแถว"

## ก่อนเริ่ม

- [ ] ถามหัวหน้าทีมว่าครั้งนี้ใช้ **เอกสารชนิดไหน** (เช่น จดหมายขอเอกสารเพิ่มเติม)
- [ ] ข้อมูลลูกค้าเก็บและเปิดเฉพาะในพื้นที่ทำงานที่บริษัทอนุญาต **ห้ามส่งไฟล์ลูกค้าทางอีเมลส่วนตัวหรือแอปแชต**
- [ ] ดูว่าอยู่ก่อนวันตัดรอบหรือยัง (วันตัดรอบ: ____________ ถามหัวหน้าทีม)
- [ ] ไฟล์ต้นทางเป็น `.xlsx` (ไม่ใช่ `.xls` หรือ `.csv`)

## ขั้นตอนทั้งหมด

### ขั้นที่ 1 เลือกชนิดเอกสารและดาวน์โหลดไฟล์แม่แบบ

1. เปิดระบบ แล้วกด **เอกสาร → สร้างชุดงานใหม่**
2. เลือก **ชนิดเอกสาร** ที่ต้องการ
3. กด **ดาวน์โหลดไฟล์แม่แบบ Excel**

> **ทำไมต้องใช้ไฟล์แม่แบบ?** ระบบอ่านไฟล์ตามหัวคอลัมน์ที่กำหนด ถ้าใช้ไฟล์เก่าที่เก็บไว้ ระบบจะบอกว่าเป็นเวอร์ชันเก่า (เหมือนใช้ฟอร์มกระดาษรุ่นเก่า)

### ขั้นที่ 2 กรอกข้อมูล

- ไฟล์แม่แบบมีแผ่น **"วิธีกรอก"** ให้อ่านก่อน
- **หนึ่งแถว = หนึ่งรายการ** (หนึ่งฉบับ หรือหนึ่งคำขอ)
- **ห้ามเปลี่ยนชื่อหัวคอลัมน์ ห้ามเพิ่ม/ลบคอลัมน์ ห้ามรวมเซลล์ (Merge cells)**
- ช่องที่มีลูกศรลงให้ **เลือกจากรายการ** ห้ามพิมพ์เอง
- ช่องวันที่ ให้พิมพ์เป็นวันที่ใน Excel ตามปกติ (เช่น `1/1/2026`) อย่าพิมพ์เป็นข้อความ
- ห้ามใช้สูตรที่แสดง `#N/A` `#REF!` หรือค่า error อื่น (ถ้าใช้สูตร ให้ **วางเป็นค่า** ก่อน)
- ช่องที่ต้องใส่หลายรายการ (เช่น รายการเอกสารที่ขอ) ให้ทำตามตัวอย่างในแผ่น "วิธีกรอก"
- บันทึกเป็น **.xlsx**

### ขั้นที่ 3 อัปโหลด

1. กด **อัปโหลดไฟล์ Excel** แล้วเลือกไฟล์
2. รอจนระบบแสดง **"ตรวจเสร็จแล้ว"** (อย่าปิดหน้าจอ)

### ขั้นที่ 4 อ่านผลตรวจ

ระบบจะแสดงตัวเลขสรุป เปรียบเสมือนกล่องแยกจดหมาย:

| กลุ่ม | ความหมาย | ต้องทำอะไร |
|---|---|---|
| ✅ **พร้อมสร้าง** | แถวถูกต้อง จะได้รับเอกสาร | ไม่ต้องทำอะไร |
| ⚠️ **ต้องแก้** | มีข้อมูลผิดหรือขาด | **ต้องแก้ก่อน** ไม่เช่นนั้นแถวนี้จะไม่ได้เอกสาร |
| ➖ **ข้าม** | แถวนี้ไม่เข้าเงื่อนไขของเอกสารนี้ (ไม่ใช่ข้อผิดพลาด) | ตรวจว่าตรงกับที่คาดไว้ |
| 🔁 **ซ้ำ** | พบแถวที่เหมือนกัน หรือเคยออกเอกสารนี้ไปแล้ว | ตรวจว่าตั้งใจให้ซ้ำหรือไม่ แจ้งผู้อนุมัติ |
| ❓ **ขัดแย้ง** | ข้อมูลในแถวขัดกันเอง | ตรวจกับต้นทางข้อมูล |

**ตรวจว่าตัวเลขรวมกันครบ:** แถวทั้งหมดในไฟล์ = พร้อมสร้าง + ต้องแก้ + ข้าม + ซ้ำ + ขัดแย้ง ถ้ารวมกันแล้วไม่เท่ากับจำนวนแถวที่คุณเตรียมไว้ **อย่าไปต่อ** ให้แจ้งหัวหน้าทีม

กด **ดาวน์โหลดรายงานแถวที่ต้องแก้** จะได้ไฟล์ที่บอก **เลขแถว** และ **เหตุผลเป็นภาษาไทย**

### ขั้นที่ 5 แก้ไฟล์และอัปโหลดใหม่ (ถ้ามีแถวต้องแก้)

1. เปิดไฟล์ Excel เดิมของคุณ แก้ตามรายงาน
2. บันทึก แล้วกด **อัปโหลดไฟล์ใหม่** (ระบบจะเก็บประวัติของรอบก่อนไว้ ไม่ถูกเขียนทับ)
3. ตรวจผลอีกครั้งจนไม่มีแถว "ต้องแก้" ที่ไม่คาดไว้

> **ถ้าบางแถวแก้ไม่ได้ทันที:** ถามหัวหน้าทีมว่านโยบายของเอกสารนี้ให้ **ปล่อยเฉพาะแถวที่ถูกก่อน** หรือ **ต้องรอให้ถูกทั้งชุด** อย่าตัดสินใจเอง

### ขั้นที่ 6 ดูตัวอย่าง (Preview)

กด **ดูตัวอย่าง** ระบบจะแสดงตัวอย่างบางฉบับ ตรวจ 6 อย่างนี้:

1. **ชื่อ** ถูกต้อง และไม่มีคำนำหน้า/คำซ้ำ (เช่น "คุณ คุณ...")
2. **เลขที่เอกสาร/เลขกรมธรรม์** ตรงกับไฟล์ Excel
3. **วันที่** ถูกต้อง และปีเป็นแบบที่ทีมกำหนด (พ.ศ. หรือ ค.ศ.)
4. **รายการที่ระบุในเอกสาร** ครบ ตัวเลขข้อเรียงถูก
5. **ภาษาไทย** อ่านได้ ไม่มีตัวอักษรเพี้ยนหรือสระ/วรรณยุกต์ลอย
6. **ไม่มีช่องว่างค้าง** เช่น `< >` หรือ `{{ }}`

> ตัวอย่างเป็นเพียงบางส่วน ระบบตรวจฉบับอื่นให้อัตโนมัติ แต่ **อย่าข้ามการดูตัวอย่าง** เพราะบางข้อผิดพลาดมองเห็นได้ด้วยตาเท่านั้น

### ขั้นที่ 7 ขออนุมัติ

1. กด **ขออนุมัติ**
2. ระบบส่งแจ้งผู้อนุมัติที่ทีมกำหนด (ชื่อ: ____________ สำรอง: ____________)
3. ผู้อนุมัติจะเห็นตัวอย่าง **และรายการแถวที่ข้าม/ซ้ำ/ผิด** แล้วกดอนุมัติหรือปฏิเสธพร้อมเหตุผล

> **สำหรับเอกสารระดับสำคัญ ผู้อนุมัติต้องเป็นคนละคนกับผู้อัปโหลด** คุณอนุมัติชุดงานของตัวเองไม่ได้ ซึ่งเป็นการออกแบบตั้งใจ ไม่ใช่ระบบเสีย

> **ถ้าแก้ข้อมูลหลังขออนุมัติ** ต้องขออนุมัติใหม่ (ระบบผูกการอนุมัติกับข้อมูลที่ตรวจแล้ว)

### ขั้นที่ 8 ดาวน์โหลดและส่ง

1. เมื่ออนุมัติแล้ว ระบบสร้าง PDF ทั้งชุดและตรวจอีกรอบ
2. ไปที่ **ชุดงานที่เสร็จแล้ว** ดาวน์โหลด PDF และ **รายงานสรุปชุดงาน**
3. **ส่งตามช่องทางที่บริษัทกำหนดเท่านั้น** ระบบนี้ **ไม่ส่งเอกสารถึงลูกค้าให้**
4. กลับมากด **บันทึกว่าส่งแล้ว** เพื่อให้ทีมรู้สถานะ

## สรุปวงจรทุก 2 สัปดาห์ (หรือตามรอบของทีมคุณ)

| เมื่อไร | ใครทำ | ทำอะไร |
|---|---|---|
| ก่อนวันตัดรอบ | ผู้เตรียมไฟล์ | ส่งออกข้อมูล กรอกไฟล์แม่แบบ ตรวจด้วยตาก่อนอัปโหลด |
| วันตัดรอบ | ผู้เตรียมไฟล์ | อัปโหลด อ่านผลตรวจ แก้ถ้ามี |
| หลังข้อมูลถูกต้อง | ผู้เตรียมไฟล์ | ดูตัวอย่าง ขออนุมัติ |
| หลังขออนุมัติ | ผู้อนุมัติ | ตรวจ ตัวอย่าง และรายการยกเว้น แล้วตัดสินใจ |
| หลังอนุมัติ | ทีมส่ง | ดาวน์โหลด ส่งตามช่องทาง บันทึกว่าส่งแล้ว |
| จบรอบ | ทีม | เก็บเลขชุดงานไว้ ถ้ามีปัญหาในรอบนี้ จดไว้ในบันทึกปัญหา |

> ระบบอาจเตือนก่อนวันตัดรอบ แต่ **การเตือนไม่ใช่การอนุมัติหรือการส่ง**

## ปัญหาที่พบบ่อยและวิธีแก้

| ข้อความ/อาการ | หมายความว่า | แก้อย่างไร |
|---|---|---|
| "ไฟล์ไม่ตรงแม่แบบ" / "ขาดคอลัมน์ …" | มีการเปลี่ยนชื่อหัวคอลัมน์ ลบ หรือเพิ่มคอลัมน์ | ดาวน์โหลดแม่แบบใหม่ แล้ววางข้อมูลกลับ ห้ามแก้หัวคอลัมน์ |
| "ไฟล์เป็นแม่แบบเวอร์ชันเก่า" | ใช้ไฟล์ที่เก็บไว้นาน | ดาวน์โหลดแม่แบบล่าสุดของชนิดเอกสารนั้น |
| "วันที่ไม่ถูกต้อง" | ช่องวันที่เป็นข้อความหรือพิมพ์ผิด | พิมพ์เป็นวันที่ใน Excel (คลิกขวา → จัดรูปแบบเซลล์ → วันที่) |
| "วันสิ้นสุดก่อนวันเริ่ม" | สลับวันที่ผิดช่อง | ตรวจว่า วันเริ่ม ≤ วันสิ้นสุด |
| "สถานะไม่รู้จัก" | พิมพ์ผิด หรือมีสถานะใหม่ที่ระบบยังไม่รู้จัก | เลือกจากรายการในช่อง ถ้าไม่มีให้แจ้งหัวหน้าทีม **อย่าเดาเอง** |
| "ชื่อเอกสารไม่รู้จัก" | ชื่อรายการไม่อยู่ในตารางชื่อมาตรฐาน | เปลี่ยนเป็นชื่อมาตรฐาน หรือแจ้งเจ้าของเอกสารให้เพิ่มชื่อ **อย่าแปลเอง** |
| "รายการเอกสารอ่านไม่ได้" | พิมพ์รายการผิดรูปแบบ (ขาดเครื่องหมายหรือวงเล็บ) | ทำตามตัวอย่างในแผ่น "วิธีกรอก" |
| "ข้อมูลขัดแย้ง" | เช่น สถานะอนุมัติแล้ว แต่ยังมีรายการเอกสารที่ขอ | ตรวจกับต้นทาง แก้ให้ตรงกัน |
| "พบแถวซ้ำ" | แถวเหมือนกันทุกช่อง หรือเคยออกแล้ว | ตรวจว่าซ้ำจริงไหม ลบแถวที่ไม่ต้องการ หรือแจ้งผู้อนุมัติถ้าต้องการให้ซ้ำ |
| กด "สร้าง" สองครั้ง / อัปโหลดไฟล์เดิมซ้ำ | — | ระบบจะแสดงชุดงานเดิม **ไม่สร้างซ้ำเงียบ ๆ** ให้เลือก "ใช้ของเดิม" หรือ "ออกใหม่" (ต้องระบุเหตุผล) |
| หน้าจอค้าง / ไม่แสดงผล | — | รอ 2–3 นาที รีเฟรชหน้า ถ้าเหมือนเดิม **อย่าอัปโหลดซ้ำ** แจ้งหัวหน้าทีมพร้อมเลขชุดงาน (ถ้ามี) |
| ดาวน์โหลดไม่ได้ | ชุดงานอาจยังไม่อนุมัติ หรือคุณไม่มีสิทธิ์ | ตรวจสถานะชุดงาน ถ้าอนุมัติแล้วแต่ยังไม่ได้ ให้แจ้งหัวหน้าทีม |

## ทำและไม่ทำ

**ทำ**
- ตรวจตัวอย่างทุกครั้ง
- เก็บเลขชุดงานไว้จนกว่าจะส่งและบันทึกเสร็จ
- แจ้งทันทีเมื่อเห็นว่าอาจส่งผิดคนหรือผิดเอกสาร
- ใช้ช่องทางที่บริษัทอนุมัติเท่านั้น

**ไม่ทำ**
- ไม่แก้ไฟล์ PDF ด้วยมือ (แก้ที่ Excel แล้วสร้างใหม่)
- ไม่ส่ง PDF ที่ยังไม่อนุมัติ หรือชุดงานที่ระบบเตือนผิดปกติ
- ไม่ส่งข้อมูลลูกค้าในอีเมลหรือแชตสำหรับขอความช่วยเหลือ (ส่งแค่ **เลขชุดงาน + เลขแถว** ก็พอ)
- ไม่แชร์รหัสผ่านหรือสิทธิ์การเข้าใช้ให้เพื่อนร่วมงาน
- ไม่ให้คนอื่นอนุมัติแทนด้วยบัญชีของคุณ

## ถ้ามีอะไรดูผิดปกติ ให้ทำตามนี้ (ทันที)

1. **หยุด** อย่าส่งเอกสารใด ๆ จากชุดงานนั้น
2. กด **หยุดชุดงาน** (ถ้ามีปุ่ม) หรือแจ้งผู้อนุมัติให้หยุด
3. จดข้อมูลสั้น ๆ: **เลขชุดงาน, เลขแถว, สิ่งที่เห็นว่าผิด**
4. แจ้งหัวหน้าทีมตามช่องทางที่บริษัทกำหนด
5. **ถ้าเอกสารถูกส่งไปแล้ว** ให้บอกด้วยทันที เพราะเป็นเรื่องเร่งด่วน (อาจเกี่ยวกับข้อมูลส่วนบุคคลของลูกค้า)

## คำถามที่พบบ่อย

**ระบบใช้ AI เขียนจดหมายไหม?**
ไม่ ข้อความจดหมายมาจากแบบฟอร์มที่ได้รับอนุมัติแล้ว ระบบเติมแค่ข้อมูลจากไฟล์ Excel ของคุณ ข้อมูลลูกค้าไม่ถูกส่งออกไปให้บริการ AI ภายนอก (ตามที่ออกแบบ)

**ฉันแก้ข้อความในจดหมายได้ไหม?**
ไม่ได้ในขั้นนี้ ถ้าต้องการเปลี่ยนถ้อยคำ แจ้ง **เจ้าของแบบฟอร์ม** ซึ่งจะออกเวอร์ชันใหม่ผ่านการอนุมัติ

**ทำไมบางแถวถึง "ข้าม"?**
แถวนั้นไม่เข้าเงื่อนไขของเอกสารชนิดนี้ (เช่น เรื่องที่อนุมัติแล้วไม่ต้องขอเอกสารเพิ่ม) ไม่ใช่ข้อผิดพลาด แต่ให้ตรวจว่าตรงกับที่คุณคาดไว้

**ฉันอัปโหลดผิดไฟล์ต้องทำอย่างไร?**
ถ้ายังไม่ได้ขออนุมัติ ให้ยกเลิกชุดงานแล้วเริ่มใหม่ ถ้าขออนุมัติไปแล้ว ให้แจ้งผู้อนุมัติ **ไม่อนุมัติ** พร้อมเหตุผล อย่าปล่อยให้อนุมัติแล้วค่อยแก้

**ต้องการเอกสารชนิดใหม่ที่ไม่มีในรายการ?**
แจ้งหัวหน้าทีมเพื่อติดต่อเจ้าของแพลตฟอร์ม ระบบรองรับเฉพาะชนิดเอกสารที่ผ่านการตั้งค่าและอนุมัติแล้ว

**ข้อมูลของฉันถูกเก็บนานแค่ไหน?**
ตามนโยบายเก็บข้อมูลที่บริษัทกำหนด (ระยะเวลา: ____________ ถามหัวหน้าทีม/DPO)

## คำศัพท์ (ภาษาง่าย)

| คำ | ความหมาย |
|---|---|
| **ชุดงาน (Batch)** | ไฟล์ Excel หนึ่งไฟล์ที่อัปโหลด 1 รอบ และเอกสารทั้งหมดที่ได้จากไฟล์นั้น |
| **ไฟล์แม่แบบ** | Excel เปล่าที่ระบบเตรียมให้ มีหัวคอลัมน์ถูกต้อง |
| **ตัวอย่าง (Preview)** | จดหมายตัวอย่างก่อนปล่อยจริง |
| **ผู้อนุมัติ** | ผู้ที่ตรวจแล้วอนุญาตให้ปล่อยชุดงาน |
| **รายงานสรุปชุดงาน (Manifest)** | ใบสรุปว่าสร้างกี่ฉบับ ข้ามกี่แถว ผิดกี่แถว |
| **เวอร์ชันแบบฟอร์ม** | เลขที่บอกว่าใช้ถ้อยคำฉบับไหน (เปลี่ยนถ้อยคำ = เลขเวอร์ชันเปลี่ยน) |
