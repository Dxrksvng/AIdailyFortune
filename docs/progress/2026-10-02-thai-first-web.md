# 2026-10-02 Thai-first Daily Compass web

**What changed.** `as4/poc` UI is now Thai by default with an EN toggle (`public/i18n.js`, Thai text lives in `index.html`). New: bento "common questions" grid, scrollytelling chapters 03 and 05, **Years ahead** screen (`lib/life.js`, `POST /api/life-timeline`, 1-10 years), **Colour / ritual / cautions** screen (`lib/ritual.js`, `POST /api/ritual`), Thai tarot names for all 78 cards (`lib/th.js`), province picker for birth place, new Oracle intents: accuracy, support (stress), life-timeline, ritual, job-this-month plan.
**Why.** Request for a Thai fortune site covering day/week/month/year x love/career/money/study, multi-year outlook, remedies, colours, cautions, common questions; motion style from the reference video.
**Decisions.** (1) "Which method is most accurate" gets an honest no-ranking answer, no score. (2) Colours/Buddha postures are labelled cultural tradition, mapping typed from general knowledge, NOT source-verified. (3) No deity is assigned. (4) Multi-year view = Jupiter/Saturn contacts sampled 4x/year + Vimshottari period; wording is fixed templates; no dated events.
**Bug fixed.** Thai `ยา` (medicine) matched inside `อยาก`, so "อยากรู้ว่าจะได้งานไหม" was refused as high-stakes (`lib/oracle.js` routing).
**Affected.** `docs`-level mismatch remains: graded PDF A4 is tarot-only; ANSWER.md/POC are multi-method. `npm run capture` (scripts/capture.mjs) still looks for English headings and needs updating.
**Next.** Reconcile PDF A4 with this POC; verify hotline 1323 and weekday colour/posture mapping against official sources; Thai text for 64 hexagram themes and Vedic nakshatra names; real mobile/screen-reader check.
